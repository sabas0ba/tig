pkt-line (gitprotocol-common) の符号化・復号。

pkt-line は「4 桁 16 進の長さ + データ」の列で、長さ 0000 (flush) / 0001 (delim) / 0002 (response-end) は区切りとして予約される。protocol v2 の request / response は全てこの形式で運ばれる。
