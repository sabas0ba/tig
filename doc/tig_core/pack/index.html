packfile (version 2) の解析。

pack は「12 byte header + object entry の列 + SHA-1 trailer」から成る。entry の 圧縮後長は記録されないため、先頭から順に伸長しながら境界を求める。parse 時に 全 entry を一度 materialize して oid を確定し、oid 順の index (entry あたり 24 byte) を構築する。object の内容は保持せず、読み出しのたびに伸長し直す (メモリを CPU で贖う方針)。
