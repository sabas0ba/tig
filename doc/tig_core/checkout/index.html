tree の展開 (checkout)。

filesystem は持たず、tree を辿って path / 種別 / 内容を callback で渡す。 ファイルへの書き出しや権限の設定は frontend (CLI 等) の責務とする。 再帰は使わず、明示的な stack で辿る。

entry の種別。git の mode から導出する。

Functions§

walk
tree 直下から再帰的に entry を列挙し、visit(path, kind, content) を呼ぶ。 path は ‘/’ 区切り (先頭に ‘/’ なし)。列挙順は tree の格納順 (名前順)。
